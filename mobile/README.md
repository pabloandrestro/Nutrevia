# App móvil de Nutrevia

La instalación, configuración de la API y arranque del development build están documentados en la [guía de inicio](../GUIA_INICIO.md).

Desde esta carpeta, después de seguir esa guía:

```powershell
npm ci
npx expo start --dev-client --clear
```

Nutrevia utiliza módulos nativos y no funciona correctamente en Expo Go.
